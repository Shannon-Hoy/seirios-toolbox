Raster Masker

Seirios Ocean Mapping Toolbox
Mask any raster with one or more other rasters, combining several masks with AND or OR logic, then export the result in GIS-ready formats. For example: download the GEBCO 2026 grid and its TID source layer from the GEBCO download app (tick "include TID grid"), drop both here, and keep only the measured cells. Additional masks narrow further, by depth, by data type, or both, and you can load several at once. Your rasters are processed in your browser and never uploaded.

1Load rasters

Drop GeoTIFF, NetCDF (.nc), or Esri ASCII (.asc) files here or click to browse.
Floating-point data grids (e.g. GEBCO bathymetry), integer grids (e.g. TID), colour/RGB TIFFs, NetCDF grids straight from the GEBCO download app, and .asc grids are all accepted. Note .asc carries no coordinate system, so its coordinates are assumed to match the other rasters.

2Mask rules

Adds the data grid as its own mask, preset to keep values below 0. Adjust the comparison in its rule block for a different cutoff or a depth band.
Load at least one raster and assign a Data role (the raster to be masked) and one or more Mask roles (the rasters that decide which cells to keep). A raster can also mask itself, which is how you filter by the data grid’s own values: set the same file to both Data and Mask, then build the rule, for example keep elevation below 0 to drop land. Once a numeric grid is assigned as Data, a depth filter button appears here and sets that up in one click.

4Export

Applies to every export below. Reprojection resamples by nearest neighbour, fine for masks and quicklooks; for survey deliverables prefer the source CRS.
UTM zone to EPSG (the usual case): WGS 84 north = 326 + zone, south = 327 + zone. Zone
Other standards: 4326 WGS 84 geographic · 3857 Web Mercator · 3031 Antarctic Polar Stereographic · 3995 Arctic Polar Stereographic · 3413 NSIDC Sea Ice North · NAD83 UTM north = 269 + zone. Zone from longitude: floor((lon + 180) / 6) + 1.
GeoTIFF

Masked raster, georeferenced. Float32 for data grids (NoData where dropped), RGBA for colour input. Opens directly in ArcGIS Pro / QGIS.

Image GeoTIFF (rendered)

The preview colours as a georeferenced RGBA tiff, masked cells transparent, for basemaps and figures, alongside the elevation tiff. Numeric data only.

Mask GeoTIFF (0/1)

The boolean keep/drop grid itself, on the data grid, useful with Extract by Mask, SetNull or Con.

Esri ASCII grid

.asc with NODATA_value. Handy for older tools and quick text inspection. Numeric data only.

XYZ points (CSV)

lon,lat,value for every kept cell. Drag into Pro as XY data, or feed to interpolation. Numeric data only.

NetCDF (.nc)

CF-compliant classic NetCDF with lat/lon coordinates and _FillValue, the same family of format GEBCO distributes. Numeric data only.

Rendered PNG + world file

The colour preview as .png plus a .pgw so it drops into GIS georeferenced (WGS84). Two downloads.
